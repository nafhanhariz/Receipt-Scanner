# Receipt-Scanner
This is my first project using AI assisted coding, where I learn to develop a solution for a problem that has a runtime of O(n) into $O(\log^2 n)$ using a script. 

I work on automating the current process of manually updating an inventory sheet using Gemini AI API and algorithm to match the products name from receipt & invoice image with users custom products list. 

Right now, I'm working on how to accurately extract/parse out quantity from the receipt, because in unclear/uncommon case the algorithm still failed to parse out the correct quantity & unit.
